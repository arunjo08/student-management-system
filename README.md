
# 🎓 Student Management System

A beginner-friendly web application built using Python and Flask to manage student records.

## ✨ Features

- ➕ Add new student records
- 👀 View student details
- ✏️ Update student information
- 🗑️ Delete student records
- 🔍 Search students by name or department
- 💾 Store records using SQLite database

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/arunjo08/student-management-system.git
```

### 2. Open the project folder

```bash
cd student-management-system
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

Visit: `http://127.0.0.1:5000`
